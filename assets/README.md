# assets

**Empty on purpose.** The source material contained no extractable vector or raster brand
assets, and nothing here was drawn, traced or reconstructed.

- `logo.svg` — add your own mark. `components/chrome/DocFooter.jsx` renders the `wordmark` prop
  as plain bold type (`[brand]` by default); replace that span with an `<img>`.
- Webfont binaries — see `tokens/fonts.css`; Mulish stands in for the measured specimen.
- An icon set — only if a real source provides one. The format itself uses no icons beyond the
  text glyphs ⚠️ ✓ ✗ 👍 👎.
